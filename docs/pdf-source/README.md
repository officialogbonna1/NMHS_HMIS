# PDF sources

`deployment_guide.py` generates `../NMHS_HMIS_Deployment_Guide.pdf` with the
shared layout in `doclib.py`. Its content follows `../DEPLOYMENT.md`,
`render.yaml` and the code — change them together.

```bash
python3 -m venv /tmp/pdfenv && /tmp/pdfenv/bin/pip install reportlab
cd docs/pdf-source
/tmp/pdfenv/bin/python deployment_guide.py ../NMHS_HMIS_Deployment_Guide.pdf
```

Needs the DejaVu fonts (`/usr/share/fonts/truetype/dejavu/`, package
`fonts-dejavu-core`). `reportlab` is a documentation tool only and is not in
the application's `requirements.txt`.

The User Manual PDF (`../NMHS_HMIS_User_Manual.pdf`) was generated by an earlier
script that is not in the repository.
