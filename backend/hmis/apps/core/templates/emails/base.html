{% comment %} The hospital's email layout, and the only one. Every admin notification extends this: masthead, event title, a block of labelled facts, an optional summary line, and the footer. An event template supplies the title, the rows and the summary — never its own HTML shell — so the hospital is branded and laid out in one place and a new event is a small template rather than another copy of a table. Written for email clients, which is why it looks like 2004: tables rather than flexbox, inline styles rather than a stylesheet, and no web fonts. Outlook renders nothing else reliably. The hospital's name and address come from `core.HospitalSettings` (rule 31) — renaming the hospital is a row, not a deployment — with a fallback for the case where the row has not been created yet, since an email must not fail to render over a masthead. {% endcomment %} {{ title }}
